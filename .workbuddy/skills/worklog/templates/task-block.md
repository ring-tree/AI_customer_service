# 任务块模板

复制下面整段，替换尖括号内容，追加到 `工作日志.md` 当日分区的 `### 任务记录` 末尾。
四项加粗字段（任务时间 / 任务输入 / 执行过程 / 任务产出）**不得删除、不得改名**。

---

## 空模板

```markdown
#### T-<YYYYMMDD>-<NN> ｜ <动词开头的短标题，≤20 字>

- **任务时间**：<YYYY-MM-DD HH:MM> → <HH:MM>（GMT+8，约 <N> 分钟）
- **任务输入**：
  - 用户诉求：<原始诉求摘要，保留关键约束，不改语义>
  - 引用/前置：<涉及的文件路径、服务状态、上一步结论>
- **执行过程**：
  1. <步骤 + 实际命令 + 目的>
  2. <技术决策及理由；为何选 A 不选 B>
  3. <遇到的障碍 → 定位方式 → 解决方式>
- **任务产出**：
  - 文件：`<path>`（新增/修改，说明改了什么）
  - 测试：<用例数/通过数/耗时>，证据 `test-evidence/<路径>`
  - 结论：<一句话结论>
- **问题与遗留**：<无 ｜ 列表，指向问题台账编号>
- **环境终态**：<服务是否仍在运行、端口、临时文件是否清理>
```

---

## 填写样例（真实任务，可直接对照）

```markdown
#### T-20261020-01 ｜ 迁移后重部署与基础回归

- **任务时间**：2026-10-20 17:39 → 17:57（GMT+8，约 18 分钟）
- **任务输入**：
  - 用户诉求：梳理项目结构、完成本地部署，并对最基础核心功能做简单测试，记录结果与问题
  - 引用/前置：README.md、工作日志.md、三项目协同关系分析.md；三服务此前均未启动
- **执行过程**：
  1. 通读 4 份文档 + 核对目录，发现文档写 E: 盘、实际在 F: 盘；确认 node_modules/.venv/db_md 就绪，无需重装
  2. 按 class3 → class1 → class2 顺序拉起服务（复用既有环境，零代码改动）
  3. A1/A3 用 Python 脚本（显式 UTF-8）测接口；A2 用 Chrome headless + CDP 测端到端
  4. 发现 Git Bash curl -d 传中文按 GBK 发送导致乱码，改用 Python 复测；另发现 hy3 在 max_tokens 过小时 content 为空
- **任务产出**：
  - 文件：`本地部署与基础测试报告-2026-10-20.md`（新增）、`README.md`（修正 3 处 E: → F:）
  - 测试：20/20 通过（A1 8 + A3 8 + A2 UI 4），证据 `test-evidence/deploy-2026-10-20/`
  - 结论：三服务零改动部署成功、无阻断缺陷；RAG 单问 54~93s 属设计使然
- **问题与遗留**：空白输入检索环（134s）、lint 缺配置、重复 finish 帧，均低优先级
- **环境终态**：三服务运行中（11434 / 3098 / 14052），测试用 Chrome 已关闭并清理 profile
```
