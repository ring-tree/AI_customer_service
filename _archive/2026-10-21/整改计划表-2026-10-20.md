## 五、风险提示汇总

| 级别 | 风险 | 缓解 |
|---|---|---|
| **高** | 无 git 基线时做批量重命名 | 阶段 0.1 强制先 `git init` 提交 |
| **高** | 知识库改文案后忘重建向量库 | 1.1 步骤内写死"必须 REBUILD"；回归用例验证引用来源文本 |
| **中** | Windows 移动 `node_modules`/`.venv` 长路径失败 | 失败则原地 `npm ci` / 重建 venv（重建 venv 需重做 chromadb DLL 补丁，方法见 docs/archive 实施记录） |
| **中** | 引用替换漏网 | 阶段 5.2 关键词清零验证 + `npm run build` 类型检查 |
| **低** | class3 `.venv/pyvenv.cfg` 记录旧路径 | 仅创建时记录，实测不影响运行；重建时自然更新 |
| **低** | 已打开浏览器持有旧文案缓存 | 硬刷新即可，无数据风险 |
