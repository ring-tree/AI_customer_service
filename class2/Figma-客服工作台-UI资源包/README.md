# 客服工作台 UI 资源包

## 目录说明

- `01-页面效果图`：指定 Figma 节点的完整画布导出，用于教师备课和整体定位；画布包含多个方案，不建议学生直接作为页面素材引用。
- `02-原始位图`：Figma 从节点子树中提取的全部 20 张原始 PNG，已按内容和尺寸重命名。
- `03-课堂推荐切图`：筛选后的高清页面、透明主视觉、背景图、品牌图标和业务插画合集，优先发放给学生。

## 推荐使用方式

1. Figma 链接仅用于查看布局、尺寸、间距、配色和页面状态。
2. 学生编码时优先使用 `03-课堂推荐切图`，不要从整页截图中二次裁切。
3. `页面-首页默认-1672x941.png` 和 `页面-客服窗口打开-1672x941.png` 用作验收参照，不应直接作为网页背景。
4. `背景图-首页高清-1672x941.png` 适合做首页装饰背景；`主视觉-透明底-高清-612x408.png` 适合独立定位。
5. `业务插画合集-658x1258.png` 是合并图，需要使用前进一步拆分或通过 CSS 背景定位；若课堂不讲雪碧图，建议只作为备用素材。
6. 两个品牌图标为 PNG，不是 SVG；放大使用可能变糊。

## 注意事项

- 部分“棋盘格底”图片的棋盘格已经写入像素，不是真透明背景，不建议课堂使用。
- 资源包不包含字体文件；页面中文字建议使用项目现有字体栈。
- Figma 文件可能继续变化，课堂发放应以本资源包为定版快照。
- 不要在设计稿、截图或资源说明中写入 API Key、账号或其他敏感信息。
